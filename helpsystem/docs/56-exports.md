# Exports

Compositional model:  
an include file with the keywords of the equation of state model in the format of Eclipse-type simulators: component names, critical properties, acentric factors, molar masses, volume translations, interaction parameters and the composition. With the Lohrenz-Bray-Clark model, the critical volumes and the coefficients a fit to viscosities changed go along (`VCRITVIS`, `LBCCOEF`).

Black-oil tables:  
an include file with `PVTO`, `PVTG`, `PVTW` and `DENSITY`, from a depletion of the fluid with the surface separation of the study. The viscosities come from the viscosity model of the fluid, and the water properties from the steam tables.

Report:  
a web page with the fluid, the fitted variables, and the plots and tables of every experiment against the measured data.

Deviations:  
the comparison of every measured value, as CSV.
