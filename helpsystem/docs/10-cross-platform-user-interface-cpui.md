# Cross-Platform User Interface (CPUI)

This part of the manual describes the Cross-Platform UI: the interface DWSIM uses on Linux and macOS, and one of the two interfaces available on Windows. Since DWSIM 10 it is built on Avalonia and draws itself the same way on every platform, so a single description covers all of them.

The engine underneath is the one the Classic UI drives. A simulation file written by either interface opens in the other, the property packages, flash algorithms and unit operation models are the same, and a converged flowsheet gives the same numbers. What differs is how the screen is organised, and that is what the following sections describe.

The AI Assistant and the Convergence Enhancer mentioned below belong to the Patreon edition. The open source edition of DWSIM 10 ships the same Cross-Platform UI without them; everything else in this part applies to both.
