# DWSIM User Guide — Web Help System

A modern, searchable web-based version of the DWSIM User Guide, built from the LyX source (`user_guide_revised.lyx`) and 13 included `.tex` files.

## How it works

1. `build.py` parses the LyX source directly in Python (no `lyx` CLI required)
2. The 13 external `.tex` includes are flattened into the resulting LaTeX
3. Custom macros (`\CRm`, `\SIidx`, `\Ksp`) are expanded
4. Pandoc converts the consolidated LaTeX to Markdown with MathJax-friendly math
5. The Markdown is split into one page per top-level section
6. Images are copied, cross-references rewritten, and `mkdocs.yml` nav is generated

## Building

Prerequisites:

- Python 3.10+
- Pandoc (already at `C:\Program Files\Pandoc\pandoc`)
- Python packages: `pip install -r requirements.txt`

To rebuild from the LyX source:

```
python build.py
```

To preview locally:

```
mkdocs serve
```

then open `http://127.0.0.1:8000`.

To produce the final static site under `site/`:

```
mkdocs build --strict
```
