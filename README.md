### Compiling

- DWSIM can be compiled using Visual Studio 2026 or newer on Windows.
- To compile everything and run:
	- Open Visual Studio 2026 and clone this repository directly from GitHub
	- Click on the Solution object and restore NuGet packages
	- Build the solution
	- Run
