# DWSIM Core Library (.NET 6)

Copyright 2022 Daniel Medeiros and contributors

## About

This is a GUI-less version of DWSIM, targeting .NET 6.

First commit is based on DWSIM v7.5, then further modifications were made to the code (cleaning, refactoring, speed optimizations, etc).

This library is currently used by the web-based version of DWSIM and will be the heart of future releases of DWSIM for Desktop and Mobile platforms.
