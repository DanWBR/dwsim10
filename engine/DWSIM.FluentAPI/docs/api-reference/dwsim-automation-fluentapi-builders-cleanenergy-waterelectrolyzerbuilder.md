# Builders.CleanEnergy.WaterElectrolyzerBuilder

`DWSIM.Automation.FluentAPI.Builders.CleanEnergy.WaterElectrolyzerBuilder`

Fluent builder for the Water Electrolyzer unit operation. Call [`AddWaterElectrolyzer`](dwsim-automation-fluentapi-flowsheet.md) to obtain one.

### `WithEfficiencyPercent(double)`

Sets `Efficiency Percent` and returns this builder for chaining.

### `WithElectronTransfer(double)`

Sets `Electron Transfer` and returns this builder for chaining.

### `WithVoltage(double)`
