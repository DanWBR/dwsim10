# Builders.ExpanderBuilder

`DWSIM.Automation.FluentAPI.Builders.ExpanderBuilder`

Fluent builder for the Expander unit operation. Call [`AddExpander`](dwsim-automation-fluentapi-flowsheet.md) to obtain one.

## Methods

### `WithAdiabaticEfficiencyPercent(double)`

Sets `Adiabatic Efficiency Percent` and returns this builder for chaining.

### `WithCalcMode(DWSIM.UnitOperations.UnitOperations.Expander.CalculationMode)`

Sets `Calc Mode` and returns this builder for chaining.

### `WithOutletPressure(Quantity)`

Sets `Outlet Pressure` (SI) and returns this builder for chaining.

### `WithPolytropicEfficiencyPercent(double)`

Sets `Polytropic Efficiency Percent` and returns this builder for chaining.

### `WithPowerGenerated(Quantity)`

Sets `Power Generated` (SI) and returns this builder for chaining.

### `WithPressureDrop(Quantity)`

Sets `Pressure Drop` (SI) and returns this builder for chaining.

### `WithProcessPath(DWSIM.UnitOperations.UnitOperations.Expander.ProcessPathType)`

Sets `Process Path` and returns this builder for chaining.
