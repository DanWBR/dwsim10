# Builders.CompressorBuilder

`DWSIM.Automation.FluentAPI.Builders.CompressorBuilder`

Fluent builder for the Compressor unit operation. Call [`AddCompressor`](dwsim-automation-fluentapi-flowsheet.md) to obtain one.

## Methods

### `WithAdiabaticEfficiencyPercent(double)`

Sets `Adiabatic Efficiency Percent` and returns this builder for chaining.

### `WithCalcMode(DWSIM.UnitOperations.UnitOperations.Compressor.CalculationMode)`

Sets `Calc Mode` and returns this builder for chaining.

### `WithOutletPressure(Quantity)`

Sets `Outlet Pressure` (SI) and returns this builder for chaining.

### `WithPolytropicEfficiencyPercent(double)`

Sets `Polytropic Efficiency Percent` and returns this builder for chaining.

### `WithPower(Quantity)`

Sets `Power` (SI) and returns this builder for chaining.

### `WithPressureIncrease(Quantity)`

Sets `Pressure Increase` (SI) and returns this builder for chaining.

### `WithProcessPath(DWSIM.UnitOperations.UnitOperations.Compressor.ProcessPathType)`

Sets `Process Path` and returns this builder for chaining.
