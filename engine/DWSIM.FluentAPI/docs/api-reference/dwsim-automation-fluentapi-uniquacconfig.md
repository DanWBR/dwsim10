# UNIQUACConfig

`DWSIM.Automation.FluentAPI.UNIQUACConfig`

UNIQUAC binary parameter setter (A12/A21 in cal/mol; optional B12/B21 T-dependent terms).

## Methods

### `WithBinary(string, string, double, double, double, double)`

Sets the UNIQUAC binary parameters for the (`compound1`, `compound2`) pair: `a12`/`a21` in cal/mol, optional T-dependent `b12`/`b21`.
