# ExternalCatalog.Electrolyte

`DWSIM.Automation.FluentAPI.ExternalCatalog.Electrolyte`

Electrolyte / aqueous-chemistry unit operations (Plus).

## Properties

### `All`

Every electrolyte display name as a flat list.

## Fields

### `IonExchangeUnit`

Ion-exchange unit (cation / anion, equilibrium or staged-countercurrent).

### `NeutralizationReactor`

Multi-inlet neutralization reactor (electrolyte mixing + thermal balance).

### `PrecipitationReactor`

Precipitation reactor - solid formation by Ksp with Davies / Debye-Hückel activity.

### `ReverseOsmosisUnit`

Reverse-osmosis / nanofiltration / ultrafiltration membrane unit.
