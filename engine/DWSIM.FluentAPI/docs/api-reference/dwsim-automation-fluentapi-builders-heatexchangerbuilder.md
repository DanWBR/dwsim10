# Builders.HeatExchangerBuilder

`DWSIM.Automation.FluentAPI.Builders.HeatExchangerBuilder`

Fluent builder for the Heat Exchanger unit operation. Call [`AddHeatExchanger`](dwsim-automation-fluentapi-flowsheet.md) to obtain one.

## Methods

### `WithCalculationMode(DWSIM.UnitOperations.UnitOperations.HeatExchangerCalcMode)`

Sets `Calculation Mode` and returns this builder for chaining.

### `WithColdSidePressureDrop(Quantity)`

Sets `Cold Side Pressure Drop` (SI) and returns this builder for chaining.

### `WithExchangeArea(double)`

Sets `Exchange Area` and returns this builder for chaining.

### `WithGlobalUA(double)`

Sets `Global UA` and returns this builder for chaining.

### `WithHotSidePressureDrop(Quantity)`

Sets `Hot Side Pressure Drop` (SI) and returns this builder for chaining.
