# ExternalCatalog.Bioprocess

`DWSIM.Automation.FluentAPI.ExternalCatalog.Bioprocess`

Bioprocess unit operations (free, in `DWSIM.UnitOperations.dll`).

## Properties

### `All`

Every bioprocess display name as a flat list.

## Fields

### `AnaerobicDigester`

Anaerobic digester (BlackBox / ADM1-Lite / ADM1 full).

### `BiogasUpgrader`

Biogas upgrader (water-scrubbing / amine / PSA / membrane).

### `BioReactor`

BioReactor (Monod / Moser / Teissier kinetics; batch / fed-batch / continuous).

### `CellLysis`

Cell-lysis unit (homogenizer / bead mill / chemical / enzymatic / osmotic / ultrasonic).

### `Centrifuge`

Liquid-solid centrifuge (disk-stack / decanter / tubular).

### `CFBFastPyrolysis`

Circulating fluidized bed fast-pyrolysis reactor (1-D PFR with sand circulation).

### `ChromatographyColumn`

Bind-elute / flow-through / dynamic Thomas-model chromatography column.

### `CrossflowUFDF`

Crossflow ultrafiltration / diafiltration with optional Hermia fouling.

### `Crystallizer`

Cooling / evaporative / antisolvent crystallizer with polynomial solubility.

### `PretreatmentReactor`

Pretreatment reactor (dilute acid / steam-explosion / alkaline / organosolv).
