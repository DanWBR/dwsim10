# Builders.Bioprocess.CentrifugeBuilder

`DWSIM.Automation.FluentAPI.Builders.Bioprocess.CentrifugeBuilder`

Fluent builder for the Centrifuge unit operation. Call [`AddCentrifuge`](dwsim-automation-fluentapi-flowsheet.md) to obtain one.

## Methods

### `WithBowlSpeedRpm(double)`

Sets `Bowl Speed Rpm` and returns this builder for chaining.

### `WithDefaultRecoveryToHeavy(double)`

Sets `Default Recovery To Heavy` and returns this builder for chaining.

### `WithRecoveryToHeavy(string, double)`

Sets `Recovery To Heavy` and returns this builder for chaining.

### `WithSigmaFactorM2(double)`

Sets `Sigma Factor M2` and returns this builder for chaining.

### `WithTechnology(DWSIM.UnitOperations.UnitOperations.CentrifugeType)`

Sets `Technology` and returns this builder for chaining.
