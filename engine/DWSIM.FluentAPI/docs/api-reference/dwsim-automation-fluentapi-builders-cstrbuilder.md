# Builders.CSTRBuilder

`DWSIM.Automation.FluentAPI.Builders.CSTRBuilder`

Fluent builder for the CSTR unit operation. Call [`AddCSTR`](dwsim-automation-fluentapi-flowsheet.md) to obtain one.

## Methods

### `WithCatalystAmountKg(double)`

Sets `Catalyst Amount Kg` and returns this builder for chaining.

### `WithHeadspaceFraction(double)`

Sets `Headspace Fraction` and returns this builder for chaining.

### `WithIsothermalTemperature(Quantity)`

Sets `Isothermal Temperature` (SI) and returns this builder for chaining.

### `WithVolume(Quantity)`

Sets `Volume` (SI) and returns this builder for chaining.
