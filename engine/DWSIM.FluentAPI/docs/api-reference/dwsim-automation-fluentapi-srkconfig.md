# SRKConfig

`DWSIM.Automation.FluentAPI.SRKConfig`

Soave-Redlich-Kwong interaction-parameter setter. Mirrors [`PRConfig`](dwsim-automation-fluentapi-prconfig.md) but reflects on `m_pr` of an `SoaveRedlichKwong` instance.

## Methods

### `WithKij(string, string, double)`

Sets the symmetric binary interaction parameter kij for the SRK pair (`compound1`, `compound2`).
