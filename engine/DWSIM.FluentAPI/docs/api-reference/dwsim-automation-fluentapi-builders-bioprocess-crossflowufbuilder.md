# Builders.Bioprocess.CrossflowUFBuilder

`DWSIM.Automation.FluentAPI.Builders.Bioprocess.CrossflowUFBuilder`

Fluent builder for the Crossflow UF unit operation. Call [`AddCrossflowUF`](dwsim-automation-fluentapi-flowsheet.md) to obtain one.

## Methods

### `WithDefaultSievingCoefficient(double)`

Sets `Default Sieving Coefficient` and returns this builder for chaining.

### `WithDiavolumes(double)`

Sets `Diavolumes` and returns this builder for chaining.

### `WithFoulingHalfLife(Quantity)`

Sets `Fouling Half Life` (SI) and returns this builder for chaining.

### `WithMembraneArea(Quantity)`

Sets `Membrane Area` (SI) and returns this builder for chaining.

### `WithMembraneFluxKgPerM2S(double)`

Sets `Membrane Flux Kg Per M2S` and returns this builder for chaining.

### `WithOperatingMode(DWSIM.UnitOperations.UnitOperations.CrossflowUFMode)`

Sets `Operating Mode` and returns this builder for chaining.

### `WithSievingCoefficient(string, double)`

Sets `Sieving Coefficient` and returns this builder for chaining.

### `WithTransmembranePressure(Quantity)`

Sets `Transmembrane Pressure` (SI) and returns this builder for chaining.

### `WithVCF(double)`

Sets `VCF` and returns this builder for chaining.
