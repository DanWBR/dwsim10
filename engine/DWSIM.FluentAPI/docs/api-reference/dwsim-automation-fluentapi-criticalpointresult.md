# CriticalPointResult

`DWSIM.Automation.FluentAPI.CriticalPointResult`

A single mixture critical point: temperature (K), pressure (Pa), molar volume (m3/mol).

## Properties

### `MolarVolumeM3PerMol`

Critical molar volume in m3/mol.

### `PressurePa`

Critical pressure in Pascal.

### `TemperatureK`

Critical temperature in Kelvin.
