# Builders.Bioprocess.PretreatmentBuilder

`DWSIM.Automation.FluentAPI.Builders.Bioprocess.PretreatmentBuilder`

Fluent builder for the Pretreatment unit operation. Call `AddPretreatment` to obtain one.

## Methods

### `WithCelluloseConversion(double)`

Sets `Cellulose Conversion` and returns this builder for chaining.

### `WithGlucoseToHMF(double)`

Sets `Glucose To HMF` and returns this builder for chaining.

### `WithHemicelluloseConversion(double)`

Sets `Hemicellulose Conversion` and returns this builder for chaining.

### `WithLigninSolubilization(double)`

Sets `Lignin Solubilization` and returns this builder for chaining.

### `WithResidenceTime(Quantity)`

Sets `Residence Time` (SI) and returns this builder for chaining.

### `WithSeverityLogR0(double)`

Sets `Severity Log R0` and returns this builder for chaining.

### `WithSolidsLoading(double)`

Sets `Solids Loading` and returns this builder for chaining.

### `WithTechnology(DWSIM.UnitOperations.Reactors.PretreatmentType)`

Sets `Technology` and returns this builder for chaining.

### `WithXyloseToFurfural(double)`

Sets `Xylose To Furfural` and returns this builder for chaining.
