# Builders.PipeBuilder

`DWSIM.Automation.FluentAPI.Builders.PipeBuilder`

Fluent builder for the Pipe unit operation. Call [`AddPipe`](dwsim-automation-fluentapi-flowsheet.md) to obtain one.

## Properties

### `AllSectionResults`

All computed results across all pipe sections, flattened into a single list.

### `HydraulicProfile`

Hydraulic profile containing all pipe sections and their computed results.

### `ProfilePointCount`

Number of computed result points across all pipe sections.

### `ThermalProfile`

Thermal boundary-condition definitions for the pipe.
