# ExternalCatalog.Refining

`DWSIM.Automation.FluentAPI.ExternalCatalog.Refining`

Refining shortcut models (Plus, in `DistPackages\Windows_Plus\unitops`).

## Properties

### `All`

Every refining display name as a flat list.

## Fields

### `Alkylation`

HF / sulphuric-acid alkylation shortcut (i-C4 + olefin → alkylate).

### `AmineTreater`

Amine treater shortcut for H2S / CO2 absorption with HC slip.

### `Blender`

Stream blender (2-4 inlets, min/avg pressure rule).

### `CDU`

Crude distillation unit shortcut - TBP-cut splitter with logistic overlap.

### `ClausSRU`

Claus sulphur recovery unit (3-stage thermal + catalytic).

### `Coker`

Delayed coker shortcut with CCR-based coke yield and PNA-aware product slate.

### `FCC`

Fluid catalytic cracker - slate or Weekman-kinetic mode.

### `HDS`

Hydrodesulfurization with HDN + mercaptan removal options.

### `Hydrocracker`

Hydrocracker (HCR) with conversion + S/N removal targets.

### `Isomerization`

C5/C6 isomerization shortcut producing isomerate of given RON.

### `Reformer`

Catalytic reformer with severity-RON sensitivity and PNA adjustment.
